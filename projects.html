Capstone Project

Open-Source Web Security Scanner

View PDF Report →

Built an open-source security scanning framework for Northeastern University ITS to serve as a custom, scalable alternative to expensive proprietary web vulnerability scanner platforms.

The solution consists of a Jenkins-driven orchestration pipeline that processes targets from list files, initiates containers, and iteratively runs targeted scanning tools against the target scope. Python scripts process and normalize JSON/XML raw tool reports into readable unified summary formats.

  • Integrated OWASP ZAP API for automated active and passive web application vulnerability assessments.
  • Configured Nikto modules to detect outdated server configurations, default configurations, and CGI security risks.
  • Incorporated testssl.sh to verify SSL/TLS service implementations, checking for weak cipher suites and known protocol flaws.

Tech Stack:

  • Jenkins Pipelines
  • OWASP ZAP API
  • Nikto
  • testssl.sh
  • Python
  • Docker Containers
  • Linux Bash

Network Security Research

TCP Covert Network Channel Research

View PDF Report →

Researched and implemented a covert communication channel as a post-exploitation technique for stealth data exfiltration and Command & Control (C2) operations.

The custom client-server architecture encodes characters into binary, encrypts the payload, hashes chunks to ensure integrity, and sends them hidden inside the ephemeral Source Port header fields of outbound TCP packets. The listener logs and decodes the stream back into plain text.

  • Evaluated the covert channel stealth by recording pcap streams and analyzing them under Wireshark configurations.
  • Tested standard rulesets on a local Snort Intrusion Detection System (IDS), validating that the covert payloads bypass signature-based detections.
  • Documented defensive mitigation strategies, including packet normalization and protocol anomaly detections.

Tech Stack:

  • TCP/IP Protocols
  • Snort IDS
  • Wireshark
  • Python Scapy
  • Cryptography (AES)
  • Network Packet Crafting

Wireless Security Research

IEEE 802.11 Deauthentication Attack Research

View PDF Research →

Investigated the vulnerabilities of unencrypted management frames in wireless networks, evaluating practical MAC-layer Denial of Service (DoS) attacks.

The study outlines how attackers exploit the lack of authentication in 802.11 management packets to send spoofed deauthentication frames. We set up an ESP8266 NodeMCU module to scan access points, clone targeting parameters, and trigger frame storms to test deauth impact.

  • Deployed an ESP8266 NodeMCU board loaded with custom C++ firmware to act as a wireless deauther unit.
  • Evaluated impact of beacon frame spoofing (creating multiple ghost networks) and probe request floods.
  • Analyzed 802.11w Protected Management Frames (PMF) standard as a cryptographic mitigation control.

Tech Stack:

  • IEEE 802.11 Standard
  • NodeMCU ESP8266
  • C++
  • Wireless Frame Injection
  • Wi-Fi Sniffing
  • Radio Tap Header Parsing
